How a search runs

  1. The invention text is decomposed into technical elements by the coverage agent.
  2. Each element is retrieved against the local corpus through an 8-channel cascade (dense + BM25 + CPC + citation/family + query-by-example + cross-lingual), fused by weighted reciprocal rank and reranked by a cross-encoder.
  3. Every search also queries the external patent APIs (SerpApi / BigQuery / PQAI / OpenAlex) in parallel. If that federated call fails or times out, the local results are still returned — federation can never take a search down with it.
  4. Each cell of the element × reference map is then re-checked by a separate model pass asked to refute it. Only cells that survive are shown as disclosure.
  5. Results are cached, so re-opening a past search from Search history is instant and costs nothing.
