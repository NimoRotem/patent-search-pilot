Patent lookup

Type a number in any format and get the document, its family, the registers, the file and the open windows. Resolve takes a few seconds; the full file takes one to three minutes and is reused once held. An EU registered design number (005632742-0001) is answered too, from EUIPO, with its drawings; to search designs by what the product is rather than by number, use the Designs page.

A number already held comes back instantly. Refresh forces a fresh pull, which costs register calls and disk, so it is off by default.
