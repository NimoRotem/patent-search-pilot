An edge controller manages charging at electric-vehicle connectors supplied by one branch whose branch limit is below the sum of the connector ratings. Each connector has a contactor, a connector current sensor, and a control-pilot interface, and a branch current sensor measures current upstream of the contactors. At each allocation interval the controller subtracts a measured non-charging branch load and a safety reserve from the branch limit to obtain an available charging current, assigns a minimum sustaining current to the sessions that can receive it, distributes the remainder by energy deficit, sends each assigned limit on the control-pilot interface, and verifies the resulting connector current. If branch current stays above the branch limit after a reduced pilot command and a verification interval, the controller opens contactors one at a time in a stored shedding order until branch current is below that limit.
