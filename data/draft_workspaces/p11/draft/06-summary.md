This summary introduces a selection of concepts that are described further in the detailed description. It is not intended to identify essential features of the claimed subject matter or to limit the scope of the claims.

An edge controller manages charging at a plurality of electric-vehicle connectors supplied by one electrical branch whose allowable aggregate current, called the branch limit, is lower than the sum of the ratings of the connectors. Each connector of the plurality forms part of a connector station that further comprises a contactor, a connector current sensor, a control-pilot interface, and a local connector identifier. A branch current sensor measures total current on the branch upstream of the connector contactors. The controller communicates with the connector interfaces and the contactors over an isolated local bus.

The controller stores, for each active connector, a charging authorization, a requested current, a minimum sustaining current, and an energy-deficit value. At each allocation interval the controller subtracts a measured non-charging branch load and a configurable safety reserve from the branch limit to obtain an available charging current. It first assigns the minimum sustaining current to the sessions that can receive it, and then distributes the remaining portion of the available charging current according to energy deficit, so that a session that has been served less is preferred over a session that has been served more. Each assigned limit is sent through the control-pilot interface of the corresponding connector, and the resulting connector current is then verified with the connector current sensor of that same connector. Allocation is therefore closed loop, using per-connector current sensing together with independent upstream branch sensing.

The branch current sensor is an independent safety input: beyond supplying the branch measurement used in the allocation arithmetic, it governs a protection process that acts on the power path. When measured branch current remains above the branch limit after a reduced pilot command has been issued and a verification interval has elapsed, the controller opens connector contactors one at a time in a stored shedding order until measured branch current is below the branch limit.

Recovery is likewise conditioned on measurement. A contactor that has been opened by the shedding sequence is not reclosed until the connector current sensor of that connector reports zero current, the control-pilot interface of that connector reports a connected vehicle, and a randomized recovery delay has expired.

A welded-contactor condition is recorded when connector current remains above a leakage threshold after an open command has been issued to the contactor of that connector. The controller then inhibits the other contactors on the same branch and operates a local fault indicator.

The controller can receive remote schedules and authorizations through a network interface, and also stores a signed local authorization token and the last accepted branch limit in nonvolatile memory. During a network outage the controller continues already authorized sessions subject to the last accepted branch limit and the independent branch-current safety process, and does not start a newly connected session unless the local token authorizes that connector and has not expired. Meter records are appended to a tamper-evident local sequence and uploaded when communication returns.

A service input permits an installer to associate connector identifiers with physical contactors by commanding one low-energy pilot transition at a time and confirming the corresponding connector current sensor. The association is stored only after the sensed channel agrees with the commanded connector, which prevents a wiring-map error from assigning a current limit to the wrong connector.

Embodiments include a charging control system and a method of controlling charging at a plurality of electric-vehicle connectors supplied by a common electrical branch.
