A reusable height-adjustable equipment platform supports a machine above a support surface such as a roof, a floor, or a vehicle bed while keeping an equipment deck parallel to a base frame.

In one aspect, the platform comprises a base frame carrying at least three upright guide towers and an equipment deck carrying a post for each guide tower, each post sliding vertically in its guide tower. Each post carries a rack, and each guide tower carries a pinion meshing with the rack of the post that slides in that guide tower, so that rotation of the pinion raises or lowers that post. A synchronizing transmission couples the pinions of all of the guide towers so that the pinions rotate together, and a rotary input comprising a worm input shaft and a worm wheel driven by the worm input shaft and fixed to a transverse shaft of the synchronizing transmission drives the synchronizing transmission, whereby a single input rotation raises or lowers every post by the same distance and the deck does not rack in the guide towers.

In a further aspect, each guide tower carries a locking pawl mounted to pivot between a locked position engaging the rack of the post sliding in that guide tower and a released position clear of that rack, and a compression spring biases each locking pawl toward the locked position. The deck load at each post is carried through the engaged locking pawl and the guide tower rather than through the synchronizing transmission alone, so that the transmission is not the only load path under a standing machine.

In a further aspect, a release balance bar is mounted on the base frame and is connected to every locking pawl by a respective release cable, and a release handle pivots the release balance bar. Pulling and holding the release handle tensions all of the release cables together and moves all of the locking pawls to their released positions. The release balance bar is pivotable relative to the release handle so that differences in the effective lengths of the release cables are taken up by pivoting of the release balance bar and no locking pawl is left engaged with its rack while the remaining locking pawls are released. Releasing the release handle allows each compression spring to return its locking pawl into engagement with the nearest tooth of the corresponding rack.

In a further aspect, each locking pawl carries a locked-state flag that is visible through a window in the corresponding guide tower only when that locking pawl is fully engaged with a tooth of the rack, so that the state of every load lock can be confirmed before the platform is loaded.

In a further aspect, a crank socket receives a removable hand crank that turns the rotary input, and a mechanical interlock on the crank socket blocks insertion of the hand crank into the crank socket unless the release handle is in its pulled position and blocks return of the release handle from its pulled position until the hand crank is removed from the crank socket. The interlock enforces an order of operations in which the locking pawls are clear of the racks before the platform can be driven and are returned to the racks only after the drive input has been disconnected, so that a locking pawl is neither dragged across a rack tooth during adjustment nor left released after adjustment.

In a further aspect, the mesh between the worm input shaft and the worm wheel resists back-driving of the transmission by the deck load while the locking pawls carry that load.

In a further aspect, a method of adjusting the height of such a platform comprises pulling and holding the release handle to move all of the locking pawls clear of the racks, turning the rotary input to raise or lower all of the posts by the same distance while the deck remains parallel to the base frame, releasing the release handle so that each compression spring returns its locking pawl into engagement with the nearest tooth of its rack, and confirming that the locked-state flag of every locking pawl is visible through the window of the corresponding guide tower.
