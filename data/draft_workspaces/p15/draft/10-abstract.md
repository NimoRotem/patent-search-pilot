A controller allocates one electrical branch among electric vehicle connectors whose combined ratings exceed a branch current limit. Each connector channel has a contactor, a connector current sensor and a control-pilot interface. A branch current sensor measures branch current upstream of the contactors. At each allocation interval the controller subtracts a measured non-charging branch load and a configurable safety reserve from the branch current limit to obtain an available charging current, assigns a minimum sustaining current to each active connector channel that can receive it, and distributes the remainder according to stored energy-deficit values. The assigned current limits are sent through the control-pilot interfaces and verified by the connector current sensors. If branch current remains above the limit for a verification interval after a reduced pilot command, the controller opens contactors one at a time in a stored shedding order until branch current is below it.
